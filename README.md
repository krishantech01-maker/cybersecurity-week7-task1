# Advanced Vulnerability Scanning with Nessus (Week 7 - Task 1)

## Overview
This repository contains the deliverables for **Week 7 - Task 1** of the Cyber Security Internship. The project focuses on configuring custom **Tenable Nessus** scan policies (credentialed & non-credentialed), analyzing complex plugin outputs using **CVSS v3.1** and **Vulnerability Priority Rating (VPR)**, prioritizing critical risks, and integrating findings into an actionable remediation workflow.

## Repository Structure
* `docs/Custom_Nessus_Policy_Report.md` - Detailed documentation of custom Nessus policy settings (Discovery, Port Scanning, Assessment, Credentials, and Plugin Families) and tool integration notes.
* `docs/Prioritized_Vulnerabilities_and_Remediation.md` - Risk-ranked table of discovered vulnerabilities with CVSS/VPR scores and technical remediation steps.

## Tools & Frameworks Used
* **Scanner:** Tenable Nessus Essentials / Professional
* **Scoring Systems:** CVSS v3.1 & Tenable VPR (Vulnerability Priority Rating)
* **Integration Targets:** Wazuh SIEM / Jira Ticketing Workflow
